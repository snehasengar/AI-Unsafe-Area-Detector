\# AI Unsafe Area Detector



An AI-powered web application that helps users report and identify potentially unsafe areas. The system allows users to submit reports of unsafe locations, which are stored in a MongoDB database and displayed through a user-friendly interface.



\## Features



\* Report unsafe areas

\* Store reports in MongoDB

\* React-based frontend

\* Node.js and Express backend

\* REST API integration

\* Real-time report management



\## Tech Stack



\### Frontend



\* React.js

\* CSS



\### Backend



\* Node.js

\* Express.js



\### Database



\* MongoDB



\## Installation



\### Clone the repository



git clone https://github.com/snehasengar/AI-Unsafe-Area-Detector.git



\### Backend Setup



cd backend



npm install



Create a `.env` file and add:



MONGO\_URI=your\_mongodb\_connection\_string



PORT=5000



Start the server:



npm start



\### Frontend Setup



cd client



npm install



npm start
